## 🚀 Key Features

### 1. Multi-Vector MITM Detection Pipeline
* **ARP Cache Poisoning & Spoofing Detector**:
  * Detects **Default Gateway MAC Address Flipping** (Critical indicator of gateway impersonation).
  * Enforces **IP-to-MAC consistency tracking** and flags conflicting duplicate MAC associations.
  * Detects **Unsolicited ARP replies** (gratuitous replies without prior request).
  * Detects **ARP reply storms & flooding** generated by tools like `arpspoof`, `bettercap`, or `ettercap`.
* **DNS Spoofing & Hijack Detector**:
  * Identifies **Unsolicited DNS responses** (forged transaction IDs).
  * Flags **Public Domain Private IP Hijacking** (e.g. public banking domains resolving to local RFC1918 addresses).
  * Cross-validates suspicious DNS answers against authoritative **DNS-over-HTTPS (DoH)** endpoints (Cloudflare `1.1.1.1` and Google `8.8.8.8`).
* **SSL/TLS Tampering & Downgrade (SSLStrip) Detector**:
  * Detects **Known MITM Proxy CA certificates** (e.g., `mitmproxy`, `PortSwigger / Burp Suite`, `Charles Proxy`, `Fiddler`).
  * Identifies unauthorized self-signed leaf certificates on public traffic.
  * Detects **SSL Stripping / HTTP Downgrade attacks** on strict HTTPS/HSTS destinations.
* **Rogue Gateway & ICMP Redirect Detector**:
  * Detects ICMP Redirect packets (Type 5) redirecting routes through malicious intermediaries.
  * Detects rogue DHCP servers offering unauthorized default gateways.

---

### 2. Autonomous Defensive Countermeasures
When an attack is detected, MITM Sentinel doesn't just log an alert—it **actively mitigates the threat**:
* 🔒 **Static ARP Pinning & Immunity**: Locks the legitimate Gateway IP-to-MAC mapping into kernel tables as a static entry (`arp -s`), preventing poison packets from corrupting the OS ARP cache.
* 💉 **Counter-Gratuitous ARP Subnet Healing**: Broadcasts authoritative curing Gratuitous ARP packets across the subnet to re-educate the gateway and protect other local devices.
* ⛔ **Automated Firewall Isolation (Quarantine)**: Automatically generates packet filtering rules (macOS `pf` / Linux `iptables`) to drop all incoming and outgoing frames from the attacker's IP and MAC address.
* 🌐 **DNS Cache Flushing & DoH Fallback**: Purges poisoned OS DNS caches (`dscacheutil`, `systemd-resolved`) and forces local resolution through encrypted DoH.
* ⚡ **TCP RST Connection Killer**: Injects TCP RST packets to immediately terminate hijacked, cleartext, or intercepted proxy sessions.

---

### 3. Real-Time Cyber Command Web Dashboard
MITM Sentinel includes an interactive dark-mode web console:
* **Live WebSocket Telemetry**: Streaming real-time packet counters, threat events, and defense metrics.
* **Attack & Defense Timeline**: Visual log of detections and defensive actions taken.
* **Host Quarantine Tracker**: Active blacklist of blocked attacker IPs and MACs.
* **Built-in Simulation Control**: One-click buttons to inject test attacks and observe detection and defensive response in real time.

## ⚡ Installation & Setup

### Prerequisites
* Python 3.8+
* macOS or Linux
* Optional: Root/Administrator privileges for live raw packet capture and static kernel ARP binding.

### Installation
```bash
git clone https://github.com/KasuSathvikaMary/mitm-sentinel.git
cd mitm-sentinel
pip install -r requirements.txt
```

## 🖥️ Usage Guide

### 1. Run the Safe Simulation & Defense Evaluation
Demonstrates all 5 detection heuristics and automated countermeasures in seconds:
```bash
python3 src/main.py simulate
```
or via the runner script:
```bash
./scripts/run_demo.sh
```

### 2. Launch the Interactive Web Dashboard
```bash
python3 src/main.py web --port 8080
```
Open **`http://127.0.0.1:8080`** in your browser. From here you can view live telemetry, inspect quarantine tables, and trigger attacks from the interactive simulation panel.

### 3. Check Network Baseline & System Status
```bash
python3 src/main.py status
```

### 4. Run Active Live Packet Monitoring
To sniff physical interface traffic and continuously protect your network:
```bash
sudo python3 src/main.py monitor
```

## ⚙️ Configuration (`config/config.yaml`)

```yaml
system:
  interface: "en0"                  # Network interface to protect
  mode: "active"                    # "active" (detect & defend) or "passive"

detection:
  arp_spoofing:
    rate_limit_pps: 5               # Max replies/sec before flagging flood
    unsolicited_reply_alert: true   # Flag unsolicited ARP replies
    gateway_mac_flip_alert: true    # Flag gateway MAC changes

  dns_spoofing:
    doh_verification: true          # Validate queries against Cloudflare DoH
    unsolicited_response_alert: true

  ssl_tampering:
    detect_http_downgrade: true     # Detect SSL stripping
    check_known_mitm_issuers: true  # Flag mitmproxy / Burp Suite certificates

defense:
  auto_remediate: true              # Automatically trigger defense actions
  arp_pinning:
    enabled: true                   # Lock static gateway ARP entry
  attacker_isolation:
    enabled: true                   # Quarantine attacker MAC/IP
```
